# Задача 11 (вне пунктов плана — запрос пользователя): удаление отчётов со страницы

Дата: 2026-10-28. План `doc/plan_2.md` (п.1–10) к этому моменту выполнен полностью;
работа выполнена по прямому запросу: «Добавь на страницу отчётов возможность
удаления выбранных отчётов, удалить выбранные, удалить все».

## Что сделано

- `server/controllers/reports_controller.ts` — два новых маршрута:
  - `DELETE /api/reports/:id` — снимает ВСЮ триаду `<id>.json/.md/.html`
    (иначе статика `/reports/<id>.html` отдавала бы мёртвые ссылки);
    фильтрация id — та же `safe_id` (400), нет файлов на диске → 404,
    успех → `200 {"deleted":"<id>"}`.
  - `DELETE /api/reports` — чистит каталог `reports/` целиком (триады
    перечисленных отчётов + осиротевшие `.md`/`.html` без пары `.json`),
    `200 {"deleted":[…],"count":N}`; пустой каталог → `count: 0`
    (идемпотентно).
  - мелкий рефакторинг: общие хелперы `json_names`/`id_of`/`remove_report`.
- `public/index.html` — панель «Отчёты»:
  - у каждого отчёта чекбокс выборa (клик по нему НЕ открывает iframe,
    отмеченный элемент подсвечен `.checked`);
  - в шапке панели кнопки «удалить выбранные (N)» (гаснет без выбора, счётчик
    живой) и «удалить все»; обе с `confirm` — удаление необратимо;
  - «выбранные» снимаются по одному `DELETE /:id`, ошибки собираются и
    показываются в конце списком; «все» — одним `DELETE /api/reports`;
  - если удалённый отчёт был открыт в iframe — вьювер возвращается в
    исходное состояние (id открытого трекается через `dataset.open_id`);
  - после любого удаления — `load_reports()` (список всегда с диска).
- `server/routes.ts` — карта комментариев пополнена DELETE-строками.
- `tests/api/reports.test.ts` — новый describe на СВОЁМ temp-каталоге с двумя
  отчётами (иначе соседние тесты делят каталог): 200+снятие триады+список
  пустеет, 400 (safe_id), 404, DELETE / (count, каталог пуст, `readdirSync`
  == []), повторный DELETE / → `count: 0`.
- `doc/api.md` — карта endpoints 16→18 (номерация разделов сдвинута), новые
  разделы 5/6 с curl и примерами.

## Проверка критериев

- `npm run build` — зелёный;
- `npm run test:api` — зелёный (новые 5 тестов включительно);
- `npm run test:unit` — зелёный (код пула/журнала не затронут);
- страница: кнопка «удалить выбранные» disabled пока нет чекбоксов, счётчик
  обновляется на каждое изменение выбора.

## Отклонения / решения

- Удаление — физическое (не «пометка»): отчёты — артефакты прогонов,
  переживают перезапуск именно как файлы; отдельной корзины план не требует.
- bulk-эндпоинта со списком id в теле не заводили: «выбранные» — это просто
  N последовательных `DELETE /:id` (rails-семантика маршрута не расширяется,
  отчётов на странице единицы-десятки).
- `DELETE /api/reports` чистит и осиротевшие `.md`/`.html`: в каталоге отчётов
  пишет только сервер, «удалить все» должно означать пустой каталог.
