## Отклонения от плана (обоснованные)

1. **8.6 «не-ответ»**: план ожидал `180 + финальный 480/408/таймаут`; живая
   станция отвечает `100 → 502 Bad Gateway` без 180 (см. зонд). Кейс честный:
   финальный отказ станции (из допустимых 404/408/480/486/487/488/502/503/504/603)
   обязан быть зафиксирован; 180 — «если был»; при молчании станции допускается
   CANCEL по таймауту 20 с (тоже фиксируется). Для другой станции ветки
   480/408/таймаут остаются покрыты.
2. **8.5 «неверный пароль → 401/403»**: станция стенда REGISTER не чалленджит
   и пароль не проверяет (REGISTER с `-wrong` паролем → 200, см. зонд).
   Ассерты условные: отказ → строго 401/403 **и** `UNREGISTERED` (регресс
   BUG-1 — без ложного REGISTERED); принятие → фиксируется в отчёте как
   поведение стенда, итог по-прежнему берётся только из финального ответа
   (инвариант №3). На станции с включённым require-auth кейс проверит полную
   ветку 401/403 плана.
3. **id кейса «не-ответ» в реестре — `'noanswer'`** (не `'6'`): п.7.1/план
   определяют команды терминала как 1..4, «не-ответ» — отдельный п.8.6;
   строковый id не конфликтует с плановыми числами. Имя отчёта —
   `case_6_noanswer`.
4. **`--no-file-parallelism`** в `test:e2e` — стенд один, номер 9404 общий;
   юниты/api распараллеливание не затрагивает.

## Документация для будущих сессий

- Новый кейс = запись в `CASES` + (опц.) файл `tests/e2e/…test.ts`; терминал,
  `test all` и `POST /api/test_runs` подхватят без правок (списки динамические).
- Ошибка любого кейса = бросок; `run_case` пишет отчёт и при FAIL — в нём
  полная цепочка журнала прогона (срез от старта кейса, не весь журнал).
- Хранилище прогонов test_runs — память процесса (перезапуск сервера их
  теряет); id формата `run_<UTC>…_case…`, результат+журнал — `GET /:id`.
- Грабли: регистрация на станции живёт `expires=600` — убивать сервер надо
  через `quit`/SIGTERM (graceful снимает), иначе следующий прогон может
  застать «вислый» контакт (для не-ответа это критично: станция пойдёт
  звонить на старый Contact вместо 502).
- `npm run test:api` пока «No test files found» — файлы п.9 не написаны
  (следующий пункт); к п.8 отношения не имеет.
- sip.js печатает deprecated-предупреждения `reconnectionAttempts/Delay` —
  шум в stderr vitest, на работу не влияет (перенос 1-в-1 из task2, правка
  вне объёма п.8).
